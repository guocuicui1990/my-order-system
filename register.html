GitHub 自动化配置更新

系统将自动提交配置更新到GitHub仓库，GitHub Actions会自动更新config.js文件。

自动化更新流程：

  1. 点击下方按钮生成GitHub Issue链接
  2. 在新打开的页面中点击"Submit new issue"按钮
  3. GitHub Actions会自动检测到新Issue
  4. Actions工作流会自动更新config.js文件
  5. 更新完成后会自动关闭Issue
